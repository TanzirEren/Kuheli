---
name: summarize
description: Summarise text or an attached file into key points, decisions and open questions
---

Summarise the material the user provides.

- Begin with a two sentence overview.
- Then give the key points as a short bulleted list.
- Add "Decisions" and "Open questions" sections only if the text contains any.
- Keep numbers, names and dates exact. Do not add facts that are not in the text.
- If the text is long, offer to go deeper into any part.
